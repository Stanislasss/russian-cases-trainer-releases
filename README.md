# Russian Cases Trainer: downloads

Installers for [Russian Cases Trainer](https://github.com/Stanislasss/russian_cases_trainer), a desktop app for practising the six Russian cases. Pick the file for your system under **Releases**:

- **Windows:** `…_x64-setup.exe`
- **macOS:** `…_aarch64.dmg` (Apple silicon) or `…_x64.dmg` (Intel)
- **Linux:** `…_amd64.AppImage` or `…_amd64.deb`

The app updates itself when a new version comes out.

## First launch

The app isn't signed yet, so your system warns you the first time:

- **Windows:** "Windows protected your PC" → *More info* → *Run anyway*.
- **macOS:** right-click (or Control-click) the app → *Open* → *Open*.
- **Linux (AppImage):** make it executable (`chmod +x`), then run it.

## Pronunciation

Optional: *Settings → Pronunciation* downloads the speech pack (about 70 MB) from this repository's `speech-v1` release.
